# 데이터 관리

이 디렉터리에는 실제 환자 정보, 처방전 원본, 진료기록 또는 비밀정보를 저장하지 않습니다.

`sample/`에는 테스트와 문서화를 위한 비식별 합성 데이터만 둘 수 있습니다. 실제 데이터와 대용량 산출물은 팀에서 승인한 외부 스토리지에서 관리하고, 접근 방법만 문서에 기록합니다.

데이터를 추가하기 전 다음을 확인합니다.

- 개인을 식별하거나 재식별할 수 있는 정보가 없는가
- API Key, 접근 토큰, 내부 URL이 포함되지 않았는가
- 데이터 사용 범위와 출처를 기록했는가
- GitHub에 올릴 필요가 있는 최소 샘플인가
