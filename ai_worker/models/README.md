# AI 모델 파일

이 디렉터리는 로컬 개발 또는 배포 과정에서 사용하는 AI 모델 파일의 위치입니다.

모델 바이너리는 크기가 크고 배포 환경별로 관리 방식이 달라 Git에 커밋하지 않습니다. 모델 파일은 객체 스토리지, 모델 레지스트리 또는 배포 서버의 안전한 저장소에서 관리하세요.

Git에 올리지 않는 파일 예시:

- PyTorch 모델: `.pt`, `.pth`, `.ckpt`
- ONNX 모델: `.onnx`
- 기타 대용량 가중치와 임베딩 인덱스

모델의 이름, 버전, 학습 데이터 범위, 성능 지표, 다운로드 위치는 민감정보를 제외하고 별도 모델 카드 또는 `docs/ai-pipeline.md`에 기록합니다. 환자 개인정보, 원본 의료 데이터, API Key 및 접근 토큰은 이 디렉터리에 저장하지 않습니다.
