# PaddleOCR 평가 결과

## 실행 환경

- PaddleOCR 버전: 3.3.0
- 검출 모델: `PP-OCRv5_server_det`
- 인식 모델: `korean_PP-OCRv5_mobile_rec`
- 실행 환경: macOS CPU
- 문서 방향 보정: 사용하지 않음
- 문서 왜곡 보정: 사용하지 않음
- 텍스트 줄 방향 보정: 사용하지 않음

## 평가 기준

`정답 필드 수 = 1 + 약품 수 × 6`

`재현율 = 일치 필드 / 정답 필드 × 100`

`정밀도 = 일치 필드 / (일치 필드 + 오탐 필드) × 100`

약품명과 복용 시점의 단순 공백 차이는 정규화한 후 비교한다.

- 약품명·용량·횟수·복용 시점의 최종 정확도는 PNG와 같다.
- 이번 깨끗한 처방전에서는 JPG 변환이 PaddleOCR의 최종 구조화 정확도에 영향을 주지 않았다.
