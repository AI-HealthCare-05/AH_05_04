- 상태: Proposed — 정책·문구 검토 요청. 운영 고지 또는 정책 버전 승인 아님.
- 구현 담당: 김지혜. 정책 책임 검토: 권가빈. 화면 문구·위치 협의: 남한솔.

## 검토 목적과 현재 경계

PR #505는 `OCR` 목적 동의 조회·등록·철회, OCR 접수 전과 Worker 외부 호출 전 재검사,
Frontend 안내를 연결했다. 현재 LLM 입력의 안전한 분리 기준이 확정되지 않아 동의가 유효해도
LLM 호출은 생략하고 규칙 기반 OCR 결과를 사용한다. Frontend의 현행 안내에는 외부 OCR과
외부 LLM 구조화 가능성이 함께 적혀 있으나, 이는 최종 승인 문구가 아니다.

`OCR_CONSENT_POLICY_VERSION`은 기본값이 빈 문자열이며 이때 신규 동의와 외부 OCR 접수는
fail-closed다. 테스트 fixture 버전을 운영 설정으로 복사하지 않는다. 기존에 승인된 OCR 전용
고지와 버전이 있는지, 있다면 실제 적용 범위가 무엇인지 확인되지 않았다.

가빈님의 9월 14일 답변에 따라 이번 데모는 유효 동의 확인과 외부 호출 차단에 집중한다.
철회 후 과거 OCR 결과의 재노출·검수와 보관·삭제, OCR Job 없는 완전 수동 입력은 이번
데모·#458의 필수조건으로 확대하지 않는다. 실제 사용자 대상 LLM 전송 활성화는 별도 게이트다.

## 안내 문구 초안 — 적용 단계별 검토

아래 두 문구는 **동시에 게시할 문구가 아니다.** 현재 데모에서 LLM 호출이 생략되는 상태와
향후 LLM 전송을 승인·활성화한 상태를 구분하기 위한 검토안이다. 실제 표시 문구와 적용
시점은 정책·화면 책임자가 확정한다.

### A. 현재 데모: 외부 OCR 사용, LLM 전송 생략

> 처방전 이미지를 외부 OCR 서비스로 전송해 내용을 인식합니다. 인식한 처방일과 약품
> 정보는 원본 처방전과 비교해 확인·수정할 수 있습니다. 현재 인식 결과는 외부 LLM에
> 전송하지 않습니다. 동의하지 않으면 외부 OCR 처리를 시작하지 않으며, 철회하면 이후
> 외부 호출을 차단합니다.

이 문구를 사용하려면 기존 OCR 전용 고지·버전의 승인 여부를 먼저 확인한다. 기존 버전을
재사용할 수 있다고 문서만으로 결정하지 않는다. 현행 Frontend의 LLM 가능성 안내와 다르게
표시할 경우 남한솔과 화면 문구를 정렬한다.

### B. 향후: 외부 OCR과 최소화된 외부 LLM 구조화 사용

> 처방전 이미지를 외부 OCR 서비스로 전송해 내용을 인식합니다. OCR이 읽은 정보 중
> 구조화에 필요한 약품·복용 정보만 외부 LLM 서비스에 전송합니다. 원본 이미지와 OCR
> 전체 텍스트는 LLM에 보내지 않습니다. 인식·구조화 결과는 원본 처방전과 비교해
> 확인·수정할 수 있습니다. 동의하지 않으면 외부 OCR 처리를 시작하지 않으며,
> 철회하면 이후 외부 호출을 차단합니다.

B는 허용 항목과 안전한 선별 구현·검증, 최종 정책 문구, 새로운 정책 버전, 재동의,
Frontend 연결 및 기존 외부 승인 조건이 모두 충족된 뒤에만 적용한다. 이 문서는 구체
전송 항목이나 외부 Provider의 보관·삭제 조건을 확정하지 않는다.

## 정책 버전·재동의 기준 제안

1. `OCR` 목적은 유지한다. 외부 LLM 구조화를 포함하도록 고지를 바꾸는 시점에는 기존
   OCR 전용 동의를 LLM 전송 근거로 자동 확대하지 않고 **새로운 current policy version**과
   변경 안내를 사용한다. 정확한 버전 문자열과 적용 시점은 권가빈 확인 후 정한다.
2. 현재 고지·버전과 일치하는 `GRANTED` row만 유효하게 판정한다. row 없음, `WITHDRAWN`,
   이전 버전 동의, 정책 버전 미설정 및 조회 실패는 외부 호출을 차단한다. 기존 row의 버전을
   서버에서 묵시적으로 올리거나 동의를 자동 생성하지 않는다.
3. 새 안내가 적용된 뒤 기존 OCR 전용 동의자는 최초 외부 처리 전에 변경 내용을 보고
   다시 동의한다. 이후 최신 버전에 유효하게 동의한 사용자는 반복 동의창을 보지 않는다.
4. 철회는 새로운 외부 호출을 차단한다. 철회 전 이미 저장된 결과의 보관·삭제 또는
   재노출 허용을 이 문서에서 승인하지 않는다.

## 책임자 확인이 필요한 세 가지

1. **데모 안내:** A 문구가 현재 실제 동작에 맞는가? 기존에 승인된 OCR 전용 고지·버전이
   있다면 무엇이며, #505 배포 시 같은 버전을 사용할 수 있는가? 아니면 새 고지·버전이
   필요한가? — 권가빈 정책 판단, 남한솔 화면 반영
2. **향후 안내·버전:** B 문구의 외부 전송 설명과 재동의 기준이 적절한가? 실제 LLM
   전송을 허용할 정확한 항목·문구·버전 값과 적용 시점은 별도로 확정한다. — 권가빈
3. **배포 순서:** 새 버전이 승인되기 전에는 빈 `OCR_CONSENT_POLICY_VERSION`을 임의 값으로
   채우지 않는다. #505 포함 버전을 배포하면서 OCR 데모를 계속 제공하려면 승인된 버전,
   일치하는 Frontend 안내, Backend·Worker 설정 및 합성 검증을 함께 준비한다. — 권가빈·
   남한솔·송은영·김지혜

## 이 문서 PR의 범위

검토 문구와 결정 질문만 추가한다. API·DTO·DB·Worker·Frontend 실행 코드, 배포 설정,
실제 외부 호출과 운영 공개 상태는 변경하지 않는다. 합성 동의·철회 회귀 테스트는 PR #505에
이미 포함되어 있으며, 최소 전송 payload와 유효 동의 시 LLM 구조화 테스트는 허용 항목
확정 후 구현 PR에서 함께 검증한다. RLS·DB Trigger·업무용 DB 함수는 추가하지 않는다.
