# #453 OCR LLM Worker 범위 정정 기록

상태: Proposed 문서의 범위 정정 — 기존 동의·전송 개정안은 이번 PR에서 채택하지 않음.

사용자 범위 확인에 따라 #453은 기존 동기 OCR LLM 구조화를 비동기 Worker로 이관하고
기존 검수·수정·약물 추가 흐름을 유지하는 작업으로 마무리한다.

새 동의 저장소·철회 검사·전송 최소화·Frontend 동의 안내는 이번에 구현하지 않는다.
담당 리뷰어 송은영이 필요하다고 판단하면 별도 이슈에서 범위와 계약을 정한다.
이 항목들을 #453 종료나 LLM 활성화의 신규 선행조건으로 두지 않는다.
기존 #207 및 승인된 목표 문서의 상태나 공통 공개 게이트를 변경하는 결정은 아니다.

LLM 입력은 기존대로 OCR이 읽은 전체 텍스트 토큰이며 원본 이미지는 보내지 않는다.
사용자 검수는 인식 결과 확인이며 전송 동의 구현으로 표시하지 않는다.

앞선 초안에 추가했던 Local 전용 제한은 제거한다. 기존 feature flag 기본값 false는
유지하며, true와 유효한 Provider 설정을 Worker에 주입하면 OCR 다음 LLM을 실행한다.
실제 배포 설정 변경이나 외부 Provider 호출 완료를 이 문서로 주장하지 않는다.
