기초

RAG가 뭐야?

RAG는 AI가 답을 만들기 전에 믿을 수 있는 자료를 먼저 찾아오는 방식입니다. 사서가 기억으로 답하지 않고 책을 꺼내 확인하는 것과 같습니다.

왜 하필 UTF-16 정렬이야?

파이썬 기본 문자열 비교(코드포인트 순서)와 UTF-16 코드 유닛 순서가 이모지 같은 문자에서 어긋납니다. 다른 언어로 만든 로더도 같은 checksum을 재현하도록 정렬 규칙을 계약으로 못 박았습니다.

# UTF-16 순서:     U+10000 (0xD800 0xDC00)  <  U+FFFD

def utf16_sort_key(value: str) -> bytes:
    return value.encode("utf-16-be")

질문은 비밀로 다룬다

사용자 질문은 SensitiveText로 감싸서 로그·에러 메시지에 원문이 찍히지 않게 합니다. 추적은 원문 대신 질문 지문(QueryFingerprint)으로 합니다.

repr을 막아버린 래퍼

class SensitiveText:
    """A query wrapper that redacts itself in ordinary representations."""
    def reveal(self) -> str:
        return self.__value
    def __repr__(self) -> str:
        return "<redacted>"
    __str__ = __repr__
