# MFDS 나머지 16개 제품 식별·본문 사전 확인

확인일: 2026-09-15
관련 이슈: #591, #593
기준: 현우님이 전달한 17개 제품 중 노바스크를 제외한 16개

## 결론

- 16개 모두 MFDS 공식 상세에서 제품명, ITEM_SEQ, 업체, 전문/일반 구분, 성상과 유효성분 분량을 확인했다.
- 16개 상세 응답은 HTTP 200이며, 응답의 `cancelCodeName`, `cancelDate`, `cancelCode`가 모두 null이었다. 따라서 확인 시점에 취하·취소 표식이 없는 후보로 기록한다.
- 허가사항 EE, UD, NB 총 48개 XML을 조회하고 같은 제품 상세의 해당 본문 영역과 대조했다.
- 일반의약품 5개 모두 같은 ITEM_SEQ의 e약은요 NN XML을 확인했다.
- 실제 원문 보관, Source Snapshot 적재, commit 후 재조회와 RAG 인계는 수행하지 않았다. #593 환경 준비 후 #591에서 진행한다.

`취하·취소 표식 없음`은 확인 시점의 공식 응답에 대한 관찰이다. 운영 사용 승인, 향후 유효성 보장, 제조·판매 상태 확인을 뜻하지 않는다.

## 식별 시 보존할 차이

- 다이아벡스 일반정과 XR 서방정은 함량이 같아도 ITEM_SEQ와 제형, 용법용량이 다르다.
- 리피토는 아토르바스타틴칼슘삼수화물 10.85mg과 아토르바스타틴으로서 10mg을 구분한다.
- 엑스포지는 암로디핀베실산염 6.94mg, 암로디핀으로서 5mg, 발사르탄 80mg을 함께 보존한다.
- 코자는 로사르탄칼륨 50mg과 로사르탄으로서 45.8mg을 구분한다.
- 자누비아는 시타글립틴인산염수화물 128.90mg과 시타글립틴으로서 100mg을 구분한다.
- 판콜에스는 내수용과 수출용 각각의 5성분 묶음을 보존한다. 단순 중복 제거를 하지 않는다.
- 겔포스엠은 4개 향별 3성분 묶음과 100g 총량 기준을 보존한다. 12성분 복합제나 1포 분량으로 해석하지 않는다.

## 검증기 확장 결과

기존 노바스크 검증기는 모든 본문이 비어 있지 않은 `PARAGRAPH`를 가져야 한다고 가정했다. 실제 공식 XML에는 다음 변형이 있다.

- 이지엔6 UD와 지르텍 EE는 `PARAGRAPH` 없이 `ARTICLE title`에 내용이 있다.
- 겔포스엠 NB의 문서 제목은 `사용상주의사항`이다.
- 자디앙과 크레스토 일부 문단에는 `data-hwpjson` 편집기 주석 또는 표 caption이 포함된다.
- 겔포스엠과 지르텍 NN의 “사용 전에 반드시 알아야 할 내용” 문단은 공식 XML에서 공백이다.

검증기는 제목형 본문과 관측된 NB 제목 변형을 지원한다. EE/UD/NB의 `ARTICLE title`은 공식 본문으로 인정한다. NN은 7개 공식 항목의 정확한 순서와 중복·누락을 검사하고, 항목별 빈 본문을 `PARTIAL_OFFICIAL`로 반환한다. 빈 항목을 수집 실패로 바꾸거나 임의 내용을 채우지 않는다. 원문 해시는 가공 전 바이트로 계산한다.

## 적재 전 좌표 후보

실제 Snapshot과 Source 식별자가 정해지기 전 문서별 좌표를 다음 규칙으로 준비한다.

- `external_document_id`: `mfds-label:{ITEM_SEQ}:{EE|UD|NB|NN}`
- `locator`: `mfds-label/{ITEM_SEQ}/{EE|UD|NB|NN}`
- 공개 출처 URL: `https://nedrug.mfds.go.kr/pbp/cmn/xml/drb/{ITEM_SEQ}/{문서종류}`

좌표는 `build_handoff_coordinates()`가 ITEM_SEQ 형식, 문서 순서와 중복을 검사해 생성한다. `source_code`, Endpoint/Operation code, `source_version`, canonicalization version, Snapshot ID와 member ID는 #593에서 합의·준비되기 전까지 null로 유지한다. 이 좌표 후보를 현재 계약이나 적재 완료 증거로 사용하지 않는다.

## 실행 묶음

1. 1차: 다이아벡스 일반정, 리피토, 다이크로짇. 현재 검증기와 직접 호환되는 기본 단일제다.
2. 2차: 이지엔6을 포함한 일반의약품 5개. EE/UD/NB와 NN을 별도 member로 보존한다.
3. 3차: 나머지 전문의약품. 서방정, 복합제, 염·수화물 기준 함량과 업체 이관 표시를 보존한다.

실제 저장 순서는 #593 환경 준비 후 적용한다. 제품별 독립 적재 허용 여부와 Snapshot 원자성은 확정된 Operation 기준을 따른다.

## 확인 방법과 한계

공식 제품 상세에서 실제 XML 다운로드 링크만 따라갔다. 상세 페이지는 같은 MFDS 호스트의 캐시 상세로만 이동했다. 원문은 검사 중 메모리에서만 사용했고 저장소에는 공개 식별정보, URL, 원본 SHA-256과 구조 집계만 남긴다.

XML 문단과 ARTICLE 제목을 같은 제품 상세의 EE/UD/NB/NN 영역과 비교했다. 비교할 때 공백, 표시용 HTML, 편집기 주석과 표 caption을 구분했다. 이 검사는 임상 의미, 표 셀 구조, 이미지 및 허가 변경 이력을 완전히 검증하지 않는다.

e약은요 NN 확인은 기존 LIST_PATIENT_MEDICATION_GUIDES OpenAPI 자연키 문제 해결이나 전체 수집 승인 증거가 아니다. NN 경로를 실제 Source Operation에 포함하려면 #593의 Source/Endpoint/Operation 범위와 승인 상태를 먼저 고정한다.

상세 집계와 원본 해시는 [mfds-16-product-precheck.json](mfds-16-product-precheck.json)에 기록한다. 실제 DB endpoint, credential, bucket/root, 원문 전문은 포함하지 않는다.
