## 수동 회귀 최소 범위

담당자는 챗봇 전체 기능을 처음부터 반복할 필요가 없다. 자동화로 고정하기 어려운 아래 정성 항목만 승인된 합성 계정·처방으로 확인한다.

1. 실제 Provider 답변이 일반 사용자가 한 번에 이해할 수 있는가.
2. 응급·고위험 표현이 과도하게 늦거나 약하게 보이지 않는가.
3. 모바일 실기기에서 긴 답변의 읽기 흐름과 입력·키보드 사용감이 자연스러운가.

이 수동 확인은 Mock E2E 또는 결정론적 안전 테스트를 대체하지 않는다.
